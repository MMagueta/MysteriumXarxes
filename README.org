#+TITLE: Mysterium Xarxes

A personal Guix channel for free software that is not (yet) in GNU Guix.
Package modules live under the =xarxes= namespace.

It used to be called EvilGuix, back when it carried proprietary software.

* Packages

None at the moment.

* Add The Channel

Add this channel to =~/.config/guix/channels.scm=:

#+BEGIN_SRC scheme
(channel
 (name 'mysterium-xarxes)
 (url "https://github.com/MMagueta/MysteriumXarxes")
 (introduction
  (make-channel-introduction
   "419be71729183b5685df0c33d63731cd512edc57"
   (openpgp-fingerprint
    "CE25 E219 59B4 60A8 4BDF  B93F 0AD3 A126 3F9D E73E"))))
#+END_SRC

Then run:

#+BEGIN_SRC sh
guix pull
guix install <package>
#+END_SRC
